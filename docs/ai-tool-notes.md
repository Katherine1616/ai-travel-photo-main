# FORME AI 虚拟试衣：AI 工具使用说明

## 1. 使用的工具

- **Codex：**分析原始代码、检索参考项目、梳理产品状态机、实现 Vite 网页 Demo、响应式适配、自动化测试、Git 提交与 GitHub 推送。
- **OpenAI ImageGen：**依据现有商品模特图与统一人物设定，生成九种身型、六件商品及两种颜色对应的预设试穿图和基础形象图。
- **浏览器自动化：**逐步回归“选款—创建形象—生成—换款/换色—扫码承接”，检查窄屏和 1440 × 900 大屏布局、素材路径、取消生成及异常状态。
- **Git / GitHub：**按功能拆分提交，保留完整迭代记录并公开源代码。

## 2. 关键提示词（节选）

**产品与原型：**

> 设计一个商场门店 AI 虚拟试衣大屏网页原型。不要上传真人照片；大屏负责低门槛选款、匿名形象和效果比较，手机负责精确参数、库存与交易。真实后端不实现，但等待、失败、隐私和转化路径必须可演示。

**素材生成：**

> 参考当前商品模特图，保持同一张脸、正面站立、统一浅灰影棚背景和自然均匀肤色；分别生成偏瘦、标准、丰满与直筒、曲线、梨型的组合。服装版型、颜色和关键细节需与参考商品一致，不夸张或丑化身材。

**交互优化：**

> 审查从商品浏览到看到生成进度的操作成本。删除重复确认，但区分“浏览商品”和“确认试穿”；商品卡只切换商品，只有明确点击试穿按钮才触发生成。取消生成必须终止全部延迟任务并提供可见反馈。

## 3. 参考项目与取舍

- [KapiAI/codebuddy-aifit-demo](https://github.com/KapiAI/codebuddy-aifit-demo)：参考商品选择、试穿任务和结果承接方式；原项目以小程序为主，本项目重新实现为可部署的网页大屏与手机页面。
- [yisol/IDM-VTON](https://github.com/yisol/IDM-VTON)：用于理解真实虚拟试衣模型所需的人像、服装输入与推理成本。本轮未接入模型，改用预生成素材保证面试演示稳定。

仅借鉴产品结构和技术边界，没有复制上述仓库代码或素材。

## 4. 本人完成的主要工作

1. **产品判断：**确定“不拍照、匿名参数化形象”的隐私策略；将快捷表单设为主路径、手机精确填写设为次要入口；加入示例效果先行，同时保留显式试穿确认，避免浏览商品时误生成。
2. **信息架构与交互：**将小程序思路重构为独立 Web Demo；完成大屏四步导航、商品浏览、九种身型映射、分阶段等待、失败/超时、取消生成、结果调整、二维码和四类履约路径。
3. **素材与质量控制：**根据实际商品模特素材生成并整理 108 张试穿结果和 9 张基础形象；统一文件映射，修正人物身份、肤色、服装颜色和错误素材引用。
4. **工程实现：**使用 Vite、原生 JavaScript、Lucide 和 QRCode 构建前端状态机；完成响应式布局、静态素材切换、手机模拟联动、Vercel 配置、浏览器回归与 Git 版本管理。

AI 主要用于加速方案探索、编码和素材生产；最终业务流程、取舍、文案、素材筛选、交互验收及提交内容均由本人审阅和修改。
