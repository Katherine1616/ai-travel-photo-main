# FORME AI 虚拟试衣：一页产品方案

## 1. 产品目标与用户

FORME 面向商场门店附近、已经注意到某件商品但尚未决定是否试穿或购买的顾客，解决三类阻力：不愿在公共设备上传真人照片、不想立即进入试衣间、希望先比较款式再做决定。产品通过匿名虚拟形象提供低压力的“先看上身效果”，再把库存和交易承接到手机。北星指标为**每周 AI 试穿归因成交用户数**，辅助观察试穿启动率、生成完成率、扫码率、当前门店 30 分钟成交率和 7 天全渠道成交率。

## 2. 核心流程

**吸引层：**浏览当前门店商品 → 可选“先看示例效果” → 在结果页选择“换成我的轮廓”。顾客可以先看到试穿价值，再决定是否投入时间创建形象。

**个人试穿主路径：**选中商品 → 点击“创建我的形象” → 在同页选择身高范围、整体体型和身体比例 → 点击“开始生成” → 查看分阶段生成进度 → 查看结果、换色、调整形象或继续试其他款式 → 扫码到手机查看库存与购买。

已有形象时，商品卡只负责浏览和选款；顾客必须点击“使用当前形象试穿”才开始生成，避免浏览商品时误触发。结果页“换一件”返回商品首页并保留形象；“再试试其他款式”代表明确试穿意图，可直接生成。需要更精确轮廓时，可从创建页扫码到手机填写身高、体重和胸腰臀数据。

## 3. 大屏与手机分工

| 门店大屏：降低体验门槛 | 手机端：承接隐私与交易 |
| --- | --- |
| 浏览本店商品、查看示例效果 | 填写精确身体参数 |
| 创建匿名形象、生成和比较试穿效果 | 查看实时尺码与库存 |
| 换款、换色、调整形象 | 保留库存、预约试穿 |
| 展示价格和库存概况、引导扫码 | 本店取货、配送、跨店取货与支付 |
| 不登录、不支付 | 收藏或使用会员权益时再登录 |

## 4. 等待、异常与隐私

生成中展示“人物准备、服装适配、细节优化、即将完成”和预计时间，同时显示“当前形象 × 商品”。顾客可取消生成，系统停止任务并保留当前选择；失败可重试、换款或扫码查看商品；超时可继续等待。当前 Demo 的大屏结果在 45 秒倒计时后清除，生产版本应改为“无操作后清除”，二维码失效后可重新生成。

大屏不启用摄像头、不上传真人照片，也不要求账号、手机号或支付信息。身体参数仅用于当次画像匹配，不写入会员或订单。当前 Demo 二维码携带商品、画像 ID、身高区间和有效期，不包含体重或胸腰臀原始数值；生产版本应替换为短期匿名会话令牌。页面持续说明：AI 效果仅供款式、颜色和轮廓参考，不代表真实尺码与合身度。

## 5. Demo 边界

本版是可部署的纯网页原型。九种身型与六件商品、两种颜色的试穿结果均为预生成静态素材；前端用状态机模拟生成、失败、超时、库存、锁货和购买路径，不接真实模型、数据库、库存或支付系统。预生成素材与真实服务采用相同的“提交任务—等待—成功/失败”交互结构，后续可替换生成与库存数据层，而不改主流程。
